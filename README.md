# Физкультура (для населения России)

Программа "Физкультура (для населения России)" является демкой, написанной на языке программирования MS-DOS QBasic 1.0 в 2003 году.

Программа при запуске запрашивает количество людей (натуральное число, не большее 100), после чего генерирует толпу из указанного количества людей, которые занимаются физкультурой. В правом верхнем углу при этом отображается государственный флаг Российской Федерации.


# Physical Education (for the Population of Russia)

The program "Physical Education (for the Population of Russia)" is a demo written in MS-DOS QBasic 1.0 in 2003.

When launched, the program prompts for the number of people (a natural number not greater than 100). It then generates a crowd of that many people who are doing physical exercises. At the same time, the flag of the Russian Federation is displayed in the top-right corner.
